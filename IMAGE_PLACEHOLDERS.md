# Placeholder Images Guide

This file documents the placeholder images needed to complete the site design. Replace the placeholder indicators with real photos from your events.

---

## Hero Section (`/comicon-2026`)

### `hero-comicon.jpg`
- **Dimensions:** 1920×1080px (or similar 16:9 ratio)
- **Type:** Wide panoramic shot
- **Content:** Gaming event crowd, convention scene, or gaming table atmosphere
- **Style:** High energy, colorful, shows the excitement of the gaming community

- **Dimensions:** ~2100×600px (21:6 ratio)

- **Content:** Celebratory community photo, event memory, or group photo

---

## Image Guidelines

1. **File format:** JPG or WebP preferred for photos
2. **Naming:** Use lowercase with hyphens (e.g., `hero-comicon.jpg`)
3. **Placement:** Put all images in `/public/images/`
4. **Alt text:** Each image should have descriptive alt text for accessibility
5. **Quality:** Use optimized images - aim for <200KB per image
